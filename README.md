# Simple D&D 5e Character Creator
A complete character creation and level-up experience for Dungeon and Dragons 5e/5.5e for Foundry VTT.

Instead of manually dragging compendium entries onto a sheet and navigating multiple advancement screens, Simple D&D Character Creator provides a guided character-building experience. Whether you're a brand-new player creating your very first hero or a veteran building a replacement character five minutes before a session starts, this module helps you get from idea to adventure within minutes.
